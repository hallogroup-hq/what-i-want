# Visual Deconstruction Protocol

## Purpose
Inspect source images objectively before drafting prompt revisions. Separate observable factual elements from subjective interpretations.

## Core Deconstruction Checklist
1. **Subject & Demographics**
   - Visible age presentation (must be clearly adult in adult styling contexts).
   - Facial proportions, gaze vector, micro-expressions.
   - Body posture, weight distribution, hand positions, finger contacts.

2. **Wardrobe & Textiles**
   - Garment category, silhouette, seam lines.
   - Neckline geometry (scoop, sweetheart, boat, V, halter, square).
   - Closure mechanisms (buttons, zippers, ties, hooks).
   - Textile weight, weave, transparency/opacity, drape, tension.

3. **Lighting & Environment**
   - Primary key light, fill light ratio, specular reflection points.
   - Shadow logic, edge falloff, ambient bounce.
   - Background depth, lens focal compression, blur characteristics.

4. **Failure Prevention**
   - Identify potential failure modes before generation:
     - Hands interacting with props or hair.
     - Thin straps or fine jewelry susceptible to clipping.
     - Unintended identity drift across multi-turn iterations.
