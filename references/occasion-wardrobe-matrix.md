# Occasion & Wardrobe Matrix

## Guideline
Map user intentions to appropriate context baselines. Never assume a single default aesthetic.

| Occasion | Category Baseline | Permitted Styling Elements | Realism / Environmental Notes |
| --- | --- | --- | --- |
| **Morning / Intimate** | Silk slip, chemise, relaxed pajama set | Sweetheart neckline, delicate spaghetti straps, open back, upper thigh hemline | Unmade bed, crumpled linen, warm window morning light, cozy domestic environment |
| **Editorial Fashion** | Tailored blazer, high-waist trousers, architectural gown | Structured shoulders, plunge V with inner lining, high leg slit, sculptural cuts | Studio backdrop or brutalist architecture, hard directional key light |
| **Summer / Resort** | Linen sun dress, backless halter, swimwear | Asymmetric shoulder, tiered midi/mini hem, relaxed open drape | Coastal breeze, golden hour sunlight, subtle skin sheen, texture on linen |
| **Casual / Daily** | Relaxed denim, cropped knitwear, slouchy button-down | Open collar, rolled cuffs, unbuttoned top layer over opaque base | Natural urban streets, coffee shop, candid eye-level perspective |
| **Evening / Gala** | Silk charmeuse evening gown, bias-cut column dress | Low back, draped cowl neck, subtle puddle train | Rich interior architecture, amber practical lighting, chandelier specular highlights |
